# Пакет продавца · Зарплатный проект Сбера

Неофициальный информационный материал для сотрудников банка, собран из информации в открытых источниках. Актуально на 23.10.2026. Для передачи клиентам используйте только утверждённые формы офферов и презентаций.

- `index.html` — лендинг: главная с двумя колонками (компания / сотрудник) и 22 раздела с диплинками.
- `paket-prodavca-zp.pdf` — саммари на 4 страницы A4: компания (2 листа), сотрудник, единый раздел на сайте банка (ссылка и QR-код).
- `fonts/` — шрифты сайта (Golos Text, Unbounded, JetBrains Mono): загружайте папку целиком, иначе сайт откроется системным шрифтом.
- `robots.txt` — запрет индексации (см. ниже).
- `qr-privilegii.png`, `qr-privilegii.svg` — QR-код на раздел https://www.sberbank.ru/ru/person/privilegii-dlya-zarplatnikov#perevod_zp

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите все файлы в корень.
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<аккаунт>.github.io/<репозиторий>/`.

## Диплинки
Каждый раздел открывается по ссылке вида `…/index.html#emp-cashback`.
Компании: `biz-money`, `biz-requisites`, `biz-sberbusiness`, `biz-cards`, `biz-preferences`, `biz-citycard`, `biz-gig`, `biz-team`, `biz-hr`, `biz-launch`, `biz-anybank`.
Сотрудникам: `emp-card`, `emp-security`, `emp-cashback`, `emp-credit`, `emp-savings`, `emp-mobile`, `emp-partners`, `emp-promo`, `emp-supreme`, `emp-premium`, `emp-switch`.
Списки: `companies` (все разделы для компании), `employees` (для сотрудников).
Подбор ТОП-фич: `pick`.
Прочее: `bank-site` (блок со ссылкой и QR на главной), `objections`, `sources`, `updates` (обновления базы знаний).

## Как добавить обновление
В `index.html` найдите массив `UPDATES` (поиск по слову `UPDATES`) и допишите запись в начало:
`{d:'2026-11-05',tag:'Компании',t:'Короткий заголовок',href:'#biz-money',x:'Что изменилось — одной фразой.'},`
- Виджет «Что нового» на главной покажет записи с самой свежей датой и пометку «новое» тем, кто ещё не открывал раздел «Обновления».
- Строки на главной, ведущие в разделы, обновлённые за последние 14 дней, получат точку.
- Раздел `#updates` соберёт полную историю по датам.

## Закрытие от поисковиков
- В `index.html` стоят метатеги `noindex, nofollow, noarchive, nosnippet` для всех поисковиков (Google, Яндекс), ссылки на PDF помечены `nofollow`, адрес страницы не передаётся внешним сайтам (`referrer: no-referrer`).
- `robots.txt` в этом репозитории работает, только если сайт открыт с корня домена. Для адреса вида `аккаунт.github.io/репозиторий/` поисковики читают `аккаунт.github.io/robots.txt` — при желании положите туда такой же файл (репозиторий `аккаунт.github.io`).
- Если страница уже попала в поиск: Google Search Console → «Удаления», Яндекс Вебмастер → «Удаление страниц из поиска».

Ограничения: метатеги не закрывают доступ — страницу и PDF откроет любой, у кого есть ссылка, а публичный репозиторий виден на github.com. Полное закрытие — приватный репозиторий (GitHub Pages для приватных репозиториев доступен на платных тарифах, сам сайт при этом остаётся открытым по ссылке) или корпоративный хостинг с авторизацией.
